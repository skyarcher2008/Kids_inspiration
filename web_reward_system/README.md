# 🌟 学习小超人 - 奖励系统使用指南

这个系统旨在通过游戏化的方式，激励孩子完成额外的学习任务。以下是系统中各项数值和机制的详细说明。

## 1. 核心数值体系

### 💰 零花钱 (元)
*   **定义**: 这是系统中的通用货币。
*   **获取方式**: 
    *   完成每日任务（如数学题、背单词）。
    *   达成周任务目标。
    *   升级奖励。
    *   连续打卡奖励。
*   **用途**: 在“商店”页面购买实际的奖励（如零食、玩具、游戏时间）。

### ⭐ 等级 (Level) & 经验值 (Exp)
*   **定义**: 代表孩子长期坚持学习的里程碑。
*   **机制**: 
    *   每个任务除了奖励金钱外，还会奖励 **10点经验值**。
    *   经验条满了之后会自动升级。
    *   升级所需经验会随着等级提高而增加（公式：`100 + (当前等级-1) * 50`）。
*   **升级奖励**: 
    *   每次升级，系统会奖励 **当前等级 × 2 元** 的巨额奖金！
    *   *例如：升到 2 级奖励 4 元，升到 5 级奖励 10 元，升到 10 级奖励 20 元。*
    *   **设计意图**: 鼓励孩子长期积累，等级越高，单次获得的成就感越强。

### 💎 宝石 (Gem)
*   **定义**: 稀有货币，用于兑换特殊的“非物质”奖励。
*   **当前状态**: 系统预留了宝石的显示位置，但默认代码中**暂未开启自动掉落**。
*   **推荐用法 (家长指南)**:
    *   您可以将其作为**“特别表现奖”**。当孩子在考试中取得优异成绩，或者受到老师表扬时，您可以手动修改数据奖励一颗宝石。
    *   **建议兑换物**: 宝石不应该用来买零食，建议用来兑换“特权”，例如：
        *   💎 x 1 = “免做一次家务卡”
        *   💎 x 2 = “周末晚睡1小时卡”
        *   💎 x 5 = “全家去游乐园”
    *   *注：如果您懂一点代码，可以在 `index.html` 的 `checkStreak` 函数中，将连续7天奖励改为赠送宝石。*

### 🔥 连续学习 (Streak)
*   **定义**: 连续每天都至少完成一个任务的天数。
*   **机制**: 
    *   如果中断一天，计数会重置为 1。
    *   **奖励**: 每连续坚持 **7天**，系统会自动奖励 **5 元**。

## 2. 任务与奖励规则详情

### 📅 每日任务
| 任务类型 | 要求 | 奖励 | 说明 |
| :--- | :--- | :--- | :--- |
| **数学练习** | 额外做10道题 | **+1 元** | 鼓励多做练习 |
| **英语单词** | 额外背10个单词 | **+1 元** | 积累词汇量 |
| **语文阅读** | 阅读20分钟 | **+1 元** | 培养阅读习惯 |
| ... | ... | ... | 更多任务可在代码中配置 |

> **幸运暴击**: 每次完成任务有 **5%** 的概率触发“幸运暴击”，额外奖励 **1 元**！

### 📅 周任务挑战
*   **目标**: 一周内累计完成超过 **5 次** 任意任务（即完成 6 次及以上）。
*   **奖励**: **+3 元**。
*   **领取**: 达成目标后，首页的“领取3元奖励”按钮会变亮，点击即可领取。每周限领一次，周一自动重置进度。

## 3. 常见问题 (Q&A)

**Q: 数据会丢失吗？**
A: 数据保存在您当前使用的**浏览器缓存 (Local Storage)** 中。
*   只要不清除浏览器缓存，数据就会一直存在。
*   **注意**: 如果换了电脑或浏览器（比如从 Chrome 换到 Edge），数据**不会**同步。建议固定使用一台设备（如家里的平板）。

**Q: 怎么修改商品和价格？**
A: 用记事本或代码编辑器打开 `index.html`，搜索 `renderShop` 函数。
你会看到类似 `{ id: 'toy', name: '小玩具', price: 5 ... }` 的代码，直接修改 `name` (名称) 和 `price` (价格) 即可。

**Q: 孩子乱点刷钱怎么办？**
A: 这是一个基于信任的系统。
1.  您可以和孩子约定，必须先做完题，经家长检查确认后，才能去点击“完成任务”。
2.  系统有简单的记录功能，在“统计”页面可以看到最近的完成记录，您可以定期检查。

**Q: 如何备份数据？**
A: 虽然系统有自动保存，但为了保险，您可以按 `F12` 打开开发者工具，在 Console 中输入 `JSON.stringify(localStorage.getItem('learningRewardData'))` 复制出来保存到文本文件中。
