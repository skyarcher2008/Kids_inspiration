# 小勇士任务 - 儿童积分管理应用

## 项目概述

"小勇士任务"是一个专为家庭设计的移动端任务管理和积分奖励系统，旨在帮助家长培养孩子的责任感、目标意识和成就感。通过游戏化的方式，让孩子在完成任务的过程中获得积分奖励，并用积分兑换心愿，从而建立积极的行为习惯。

## 核心功能

### 1. 家长管理界面 (index.html)
- **任务管理**：创建、编辑和删除任务
- **任务审核**：审核孩子提交的任务完成情况
- **积分设置**：为不同难度和类型的任务设置积分奖励
- **数据统计**：查看任务完成统计和积分分布

### 2. 孩子操作界面 (child-view.html)
- **任务查看**：查看今日待完成任务
- **任务完成**：标记任务完成并提交说明
- **积分显示**：实时显示当前积分和进度
- **成就展示**：查看最近获得的成就

### 3. 心愿管理系统 (wishes.html)
- **心愿设定**：孩子可以设定自己的心愿目标
- **积分兑换**：用积累的积分兑换心愿
- **进度跟踪**：实时显示心愿完成进度
- **优先级管理**：设置心愿的优先级

### 4. 成就统计系统 (rewards.html)
- **成就解锁**：完成特定条件解锁成就徽章
- **成长曲线**：显示积分和任务完成的趋势
- **统计展示**：全面的数据统计和分析
- **激励机制**：通过成就系统增强孩子动力

## 技术特点

### 设计特色
- **温馨友好**：使用柔和的色彩和圆润的设计
- **移动优先**：专为移动设备优化的界面设计
- **动画效果**：丰富的动画和视觉反馈
- **儿童友好**：大按钮、清晰图标、简单操作

### 技术实现
- **纯前端应用**：使用HTML5、CSS3和JavaScript
- **数据持久化**：使用localStorage保存数据
- **动画库**：集成Anime.js实现流畅动画
- **图表展示**：使用ECharts.js进行数据可视化
- **响应式设计**：适配各种移动设备屏幕

### 交互体验
- **即时反馈**：每个操作都有明确的视觉反馈
- **庆祝动画**：任务完成和成就解锁时的特效
- **进度可视化**：直观的进度条和统计图表
- **游戏化元素**：积分、成就、等级等游戏机制

## 使用方法

### 家长操作
1. 在主页创建任务，设置积分奖励和难度
2. 审核孩子提交的任务完成情况
3. 查看统计图表了解孩子的表现
4. 管理心愿兑换请求

### 孩子操作
1. 查看每日任务列表
2. 完成任务并提交完成说明
3. 积累积分并设定心愿目标
4. 用积分兑换心愿
5. 查看成就和统计数据

## 教育价值

### 培养能力
- **责任感**：通过日常任务培养责任意识
- **目标意识**：设定心愿目标并努力实现
- **时间管理**：按时完成任务的习惯
- **成就感**：通过积分和成就获得正向反馈

### 家长参与
- **积极引导**：通过任务设置引导孩子行为
- **及时反馈**：审核任务给予肯定和建议
- **共同成长**：通过数据统计了解孩子进步

3. **视觉友好**：温馨的色彩和可爱的图标
4. **数据驱动**：详细的统计和进度跟踪
5. **移动优先**：专为手机使用优化
6. **离线可用**：纯前端实现，无需网络连接
