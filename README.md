# 小学生趣味学习乐园

面向小学三四年级学生的数学与英语学习应用，包含积分、红包和成就系统。

## 功能概览

- **数学口算练习**：简单/中等/挑战三档难度
- **英语单词记忆**：艾宾浩斯复习计划、补全单词
- **英语语法练习**：四选一题型并带解析
- **积分系统**：答对奖励积分，连对额外奖励，随机红包机制
- **成就系统**：积分、连对、答题里程碑徽章
- **数据存储**：所有数据保存在浏览器本地缓存（LocalStorage）中

## 本地运行

**前置条件：** Node.js 18+

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 访问 http://localhost:3000
```

## NAS 部署（Docker Compose）

适合家庭 NAS 部署，使用 Nginx 提供静态文件服务，并可选启用同步服务：

```bash
# 构建并启动容器
docker compose up -d --build

# 访问 http://<NAS内网IP>:8080
```

> **端口配置**：如需修改端口，请编辑 `docker-compose.yml` 文件。

### 启用跨设备同步（推荐）

同步服务会在 NAS 上启动一个轻量后端，多个设备通过同一个家庭ID共享数据。

1. 在项目根目录创建 `.env.local`：

```bash
VITE_SYNC_API_URL=http://<NAS内网IP>:8787
```

2. 重新构建前端并启动服务：

```bash
docker compose up -d --build
```

3. 在“成就与成长”页面的“跨设备同步”里生成家庭ID，并在其他设备填入同一个ID。

> **提示**：同步密码为可选项，可用于家庭内部简单保护。

## 数据说明

- **本地存储**：所有学习数据（积分、进度、成就等）均存储在浏览器的 LocalStorage 中
- **数据导入导出**：支持通过成就页面导出/导入 JSON 数据进行备份
- **单词/语法导入**：支持 CSV 和 PDF 文件导入自定义学习内容
- **跨设备同步**：启用同步服务后，可在多设备间自动同步学习进度
