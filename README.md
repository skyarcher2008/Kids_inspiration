# 小学生趣味学习乐园

面向小学三四年级学生的数学与英语学习乐园，包含积分、红包和成就系统，适合家庭 NAS 部署。

## 功能概览

- 数学口算练习：简单/中等/挑战三档
- 英语单词记忆：艾宾浩斯复习计划、补全单词
- 英语语法练习：四选一并带解析
- 积分系统：答对 +10，连对奖励，红包机制
- 成就系统：积分、连对、答题里程碑

## 本地运行

**前置条件：** Node.js 18+

1. 安装依赖
2. 启动开发服务器

## NAS 部署（Docker Compose）

已提供 Nginx 静态部署方式，适合家庭 NAS：

1. 在项目根目录执行 `docker compose up -d --build`
2. 浏览器访问 `http://<NAS内网IP>:8080`

> 如需修改端口，请编辑 docker-compose.yml。
